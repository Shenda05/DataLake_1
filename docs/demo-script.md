# 答辩演示脚本

## 演示目标

- 用最短路径展示“数据接入 -> 数据集管理 -> 查询分析 -> 数据治理 -> 任务调度 -> 日志监控”的完整闭环

## 建议账号

- 使用管理员账号 `admin / admin123`

## 推荐演示顺序

### 1. 首页开场

- 展示首页统计卡片
- 展示最近任务和最近 1 分钟事件流
- 说明平台已经具备真实数据接入、治理和调度能力

### 2. 创建数据源并导入

- 进入“数据源管理”，展示 `FILE / MYSQL` 两类数据源
- 快速创建一个 `FILE` 数据源
- 进入“数据接入”，上传一份 `CSV` 文件
- 展示导入历史中新增的一条记录

### 3. 数据集查看与导出

- 进入“数据集管理”
- 展示元数据、分页预览和关键字筛选
- 点击 `Excel` 导出，说明平台支持留档

### 4. 查询分析

- 进入“查询分析”
- 先执行一个条件查询，例如 `industry LIKE 智能`
- 再展示单表 SQL 查询
- 展示统计摘要和图表

### 5. 数据治理

- 进入“数据治理”
- 选择刚导入的数据集
- 添加两个算子，例如 `NULL_FILL + FILTER_KEEP`
- 保存流程并执行
- 展示系统生成了一个新的输出数据集

### 6. 任务调度

- 进入“任务调度”
- 创建一个 `GOVERNANCE` 任务
- 立即触发执行
- 展示任务页自动刷新和最近执行结果提示
- 可切换到一个已保存的筛选视图

### 7. 日志监控

- 进入“日志监控”
- 展示日志筛选、常用视图和导出功能
- 选中一条失败日志或历史日志
- 展示详情面板
- 如果有失败日志，点击“一键回放”

### 8. 总结收束

- 返回首页
- 用统计卡片和最新日志说明平台形成了端到端闭环

## 讲解重点

- 所有页面都接的是实时后端接口，不是本地静态 Mock
- 数据集有真实物理表、元数据和导出能力
- 治理输出会生成新的数据集，不覆盖原始数据
- 任务与日志已经形成可追踪链路
- 当前版本优先完成课程项目的 P0 闭环，增强项保留继续扩展空间
