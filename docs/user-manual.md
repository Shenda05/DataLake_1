# 用户手册

## 1. 登录

- 管理员账号：`admin / admin123`
- 普通用户账号：`operator / operator123`
- 登录成功后，系统会按角色返回可见菜单
- 如果管理员调整了当前账号的状态、角色、菜单权限或操作权限，现有会话会在下一次 profile 同步后自动更新

## 2. 数据源管理

- 管理员可创建、编辑、启停、测试和删除 `FILE` 或 `MYSQL` 数据源
- `FILE` 数据源用于上传文件
- `MYSQL` 数据源用于数据库表导入和连接测试
- `MYSQL` 数据源保存时支持“同连接处理策略”：`ALLOW / WARN / REJECT`
- 同名数据源会被直接拒绝；同连接 `WARN` 会提示但允许保存；`REJECT` 会直接阻止保存
- 测试连接是显式校验动作，平台不会维护“已测试通过”持久状态

## 3. 数据接入

### 文件导入

1. 选择数据源
2. 输入数据集名称
3. 选择业务域
4. 上传 `CSV / JSON / Excel`
5. 根据文件格式配置解析选项：
   - `CSV`：可选择编码方式，并切换“首行为表头”
   - `Excel`：可切换“首行为表头”
   - `JSON`：按对象数组自动解析，编码方式和表头开关会被忽略
6. 提交后查看导入历史

### 数据库表导入

1. 选择 `MYSQL` 数据源
2. 从自动识别的 `schema / database` 下拉中选择目标库
3. 切换 `schema / database` 后，等待数据库表列表自动刷新
4. 选择数据库表
5. 预览字段与样例数据
6. 输入数据集名称并执行导入

## 4. 数据集管理

- 查看数据集列表
- 查看字段元数据
- 分页预览数据
- 按字段和关键字筛选
- 导出 `CSV / JSON / Excel`
- 管理员可删除未被引用的数据集

## 5. 查询分析

- 条件查询支持多条件组合、`AND/OR`、时间范围、排序、分页
- SQL 查询只允许当前数据集单表查询；支持分页与排序结果视图
- 图表可与当前筛选条件联动，支持电商模板指标展示
- 查询结果可导出 `CSV / JSON / Excel`，过滤模式可按当前筛选导出全量命中数据
- 页面会展示记录数、空值数、重复数和图表

## 6. 数据治理

- 可选择输入数据集
- 可配置基础算子链
- 算子支持启用/停用；禁用算子不可用于保存或执行
- 流程步骤支持上移/下移重排
- 可保存治理流程
- 可手动执行并生成新数据集

## 7. 任务调度

- 支持 `IMPORT` 和 `GOVERNANCE` 两类任务
- 支持创建、编辑、暂停、恢复、立即执行
- 支持自动刷新
- 支持保存常用筛选视图

## 8. 日志监控

- 查看任务日志列表与详情
- 支持服务端筛选：状态、类型、操作人、时间范围、关键字
- 支持本地快速筛选：执行目标、近 7 天失败
- 支持保存常用筛选视图
- 支持导出当前筛选结果
- 对任务生成的失败日志支持一键回放
- 日志详情支持输入参数、执行步骤、结构化失败原因、操作人信息

## 9. 用户与权限

- 仅管理员可见
- 支持新增用户
- 支持修改用户名、角色、状态
- 支持重置密码
- 支持删除用户
- 支持按角色调整角色说明、菜单权限和分组操作权限
- 关键操作权限已覆盖治理流程保存、治理执行、任务配置、任务触发、数据集导出、查询结果导出、日志导出和日志回放
- 角色菜单权限或操作权限修改后，现有会话会自动同步；若浏览器仍停留旧状态，可手动刷新页面确认

## 10. 注意事项

- 导入任务重跑时，原始文件或原始数据库表需要仍然可访问
- SQL 查询不支持多表 `JOIN`
- 当前调度仍是应用内轮询，不是 Quartz
- 数据集成能力当前通过查询分析页子标签提供（基础 `JOIN/UNION`）
- 数据库表导入当前不支持“自定义 SQL 导入”，只支持选表导入
- 首页统计卡片和核心图表支持模块级跳转，但当前不携带图表点位级筛选条件深链
