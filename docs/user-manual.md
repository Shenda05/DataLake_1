# 用户手册

## 1. 登录

- 管理员账号：`admin / admin123`
- 普通用户账号：`operator / operator123`
- 登录成功后，系统会按角色返回可见菜单

## 2. 数据源管理

- 管理员可创建 `FILE` 或 `MYSQL` 数据源
- `FILE` 数据源用于上传文件
- `MYSQL` 数据源用于数据库表导入和连接测试

## 3. 数据接入

### 文件导入

1. 选择数据源
2. 输入数据集名称
3. 上传 `CSV / JSON / Excel`
4. 提交后查看导入历史

### 数据库表导入

1. 选择 `MYSQL` 数据源
2. 输入或确认 `schema / database`
3. 选择数据库表
4. 预览字段与样例数据
5. 输入数据集名称并执行导入

## 4. 数据集管理

- 查看数据集列表
- 查看字段元数据
- 分页预览数据
- 按字段和关键字筛选
- 导出 `CSV / JSON / Excel`
- 管理员可删除未被引用的数据集

## 5. 查询分析

- 条件查询支持 `LIKE / EQ / GT / LT`
- SQL 查询只允许当前数据集单表查询
- 查询结果可导出 `CSV / JSON / Excel`
- 页面会展示记录数、空值数、重复数和图表

## 6. 数据治理

- 可选择输入数据集
- 可配置基础算子链
- 可保存治理流程
- 可手动执行并生成新数据集

## 7. 任务调度

- 支持 `IMPORT` 和 `GOVERNANCE` 两类任务
- 支持创建、编辑、暂停、恢复、立即执行
- 支持自动刷新
- 支持保存常用筛选视图

## 8. 日志监控

- 查看任务日志列表与详情
- 支持状态、类型、目标、时间范围、近 7 天失败等筛选
- 支持保存常用筛选视图
- 支持导出当前筛选结果
- 对任务生成的失败日志支持一键回放

## 9. 用户与权限

- 仅管理员可见
- 支持新增用户
- 支持修改用户名、角色、状态
- 支持重置密码
- 支持删除用户

## 10. 注意事项

- 导入任务重跑时，原始文件或原始数据库表需要仍然可访问
- SQL 查询不支持多表 `JOIN`
- 当前调度仍是应用内轮询，不是 Quartz
