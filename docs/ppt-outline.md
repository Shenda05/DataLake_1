# 答辩 PPT 大纲

## 1. 项目背景

- 数据湖平台课程选题背景
- 现有痛点：数据分散、元数据缺失、治理与调度割裂

## 2. 项目目标

- 构建一个可演示的 Web 端数据湖管理平台
- 打通接入、管理、分析、治理、调度、监控闭环

## 3. 技术架构

- 前端：`Vue 3 + Element Plus + Pinia + ECharts`
- 后端：`Spring Boot + JDBC + JWT + MySQL/H2`
- 文件存储：本地文件系统

## 4. 核心功能

- 登录与权限控制
- 数据源管理
- 文件导入与数据库表导入
- 数据集与元数据管理
- 查询分析与可视化
- 数据治理
- 任务调度与日志监控

## 5. 关键实现亮点

- 每个数据集生成独立物理表
- 支持真实 `CSV / JSON / Excel / MYSQL 表` 导入
- 治理执行生成新数据集，原始数据只读保留
- 任务和日志链路可追踪
- 数据集和查询结果支持 `Excel` 导出

## 6. 演示流程

- 首页 -> 数据接入 -> 数据集 -> 查询分析 -> 数据治理 -> 任务调度 -> 日志监控

## 7. 测试与结果

- 前端构建通过
- 后端编译通过
- H2 端到端冒烟通过
- MySQL 已完成连通性定位，待实际账号补充完整联调

## 8. 团队分工

- 产品与文档
- 前端模块
- 后端模块

## 9. 当前边界

- 当前任务类型仅 `IMPORT / GOVERNANCE`
- SQL 查询只支持单表
- 调度仍是应用内轮询

## 10. 后续规划

- 细粒度权限树
- 更多数据库源接入
- Quartz / 独立调度器
- 更丰富的治理算子与审计能力
