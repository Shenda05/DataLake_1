# 测试计划

## 认证与权限

- 管理员和普通用户均可登录
- 未登录访问业务页面会被拦截
- 普通用户不可看到管理员专属菜单
- 错误密码返回明确提示
- 管理员可新增、编辑、停用和删除用户
- 系统至少保留一个启用中的管理员

## 数据接入

- CSV 文件正常导入
- JSON 文件正常导入
- Excel 文件正常导入
- MYSQL 数据库表可列出、预览并导入
- 非法文件格式被拒绝
- 超大文件被拒绝
- 导入失败可查看失败原因

## 数据集与元数据

- 数据集列表显示名称、来源、格式、创建时间和状态
- 数据集详情显示元数据和最近操作信息
- 元数据字段类型识别正确
- 数据预览支持分页、搜索和字段筛选
- 被治理流程、日志或导入记录引用的数据集不可直接删除
- 数据集支持导出 `CSV / JSON / Excel`

## 查询分析

- 条件查询支持等于、范围和包含
- SQL 查询支持单表筛选、排序和分页
- 非法 SQL 给出友好提示
- 图表接口可返回统计结果
- 查询结果支持导出 `CSV / JSON / Excel`

## 数据治理

- 空值处理算子有效
- 去重算子有效
- 字段转换算子有效
- 条件过滤算子有效
- 多算子顺序执行后生成新数据集
- 治理过程日志可追踪

## 任务调度与日志

- 可创建导入任务
- 可创建治理任务
- 支持手动触发
- 支持暂停与恢复
- 失败任务可重试
- 日志详情可查看开始时间、结束时间、状态、异常信息
- 失败日志支持一键回放
- 任务页和日志页支持保存常用筛选视图

## 端到端验收

- 管理员创建数据源并上传文件
- 普通用户查看数据集并进行查询
- 用户执行治理流程生成新数据集
- 用户创建定时任务并查看日志
- 首页展示最新统计和任务趋势
