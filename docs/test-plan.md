# 测试计划

## 认证与权限

- 管理员和普通用户均可登录
- 未登录访问业务页面会被拦截
- 普通用户不可看到管理员专属菜单
- 错误密码返回明确提示
- 管理员可新增、编辑、停用和删除用户
- 系统至少保留一个启用中的管理员

## 数据接入

- CSV 文件正常导入
- JSON 文件正常导入
- Excel 文件正常导入
- MYSQL 数据库表可列出、预览并导入
- 非法文件格式被拒绝
- 超大文件被拒绝
- 导入失败可查看失败原因

## 数据集与元数据

- 数据集列表显示名称、来源、格式、创建时间和状态
- 数据集详情显示元数据和最近操作信息
- 元数据字段类型识别正确
- 数据预览支持分页、搜索和字段筛选
- 被治理流程、日志或导入记录引用的数据集不可直接删除
- 数据集支持导出 `CSV / JSON / Excel`

## 查询分析

- 条件查询支持多条件组合（`AND / OR`）
- 条件查询支持 `TIME_RANGE / BETWEEN`
- 条件查询支持排序与分页
- SQL 查询支持单表筛选；`/queries/sql/page` 支持排序与分页
- 非法 SQL 给出友好提示
- 图表支持与当前筛选条件联动
- 电商模板（订单趋势、销售趋势、热销排行、库存预警）可稳定返回图表与表格
- 查询结果导出支持按当前筛选条件导出（过滤模式全量导出）
- 查询结果支持导出 `CSV / JSON / Excel`

## 数据治理

- 空值处理算子有效
- 去重算子有效
- 字段转换算子有效
- 条件过滤算子有效
- 算子状态支持启停，禁用算子不可保存/执行
- 编排步骤支持上移/下移后顺序可持久化
- 多算子顺序执行后生成新数据集
- 治理过程日志可追踪

## 任务调度与日志

- 可创建导入任务
- 可创建治理任务
- 支持手动触发
- 支持暂停与恢复
- 失败任务可重试
- 日志列表支持服务端筛选（类型、状态、操作人、时间范围）
- 日志列表展示操作人
- 日志详情可查看输入参数、执行步骤、结构化失败原因、操作人
- 失败日志支持一键回放
- 任务页和日志页支持保存常用筛选视图

## 端到端验收

- 管理员创建数据源并上传文件
- 用户查看数据集并进行查询
- 用户执行治理流程生成新数据集并验证治理统计
- 用户创建定时任务并查看日志筛选结果
- 首页展示最新统计和任务趋势
