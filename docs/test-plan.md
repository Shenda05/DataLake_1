# 测试计划

## 认证与权限

- 管理员和普通用户均可登录
- 未登录访问业务页面会被拦截
- 普通用户不可看到管理员专属菜单
- 错误密码返回明确提示
- 管理员可新增、编辑、停用和删除用户
- 系统至少保留一个启用中的管理员

## 数据接入

- CSV 文件正常导入
- JSON 文件正常导入
- Excel 文件正常导入
- MYSQL 数据库表可列出、预览并导入
- 非法文件格式被拒绝
- 超大文件被拒绝
- 导入失败可查看失败原因

### 数据源重复策略人工验证步骤

1. 使用管理员账号进入“数据源管理”，先创建一个 `MYSQL` 数据源，例如：`sourceName=订单库A`、`host=127.0.0.1`、`port=3306`、`dbName=ecommerce`、`username=root`，确认创建成功。
2. 再次创建一个同名数据源，保持 `sourceName=订单库A`，其余连接参数可相同或不同，期望系统直接拒绝保存，并提示“数据源名称已存在，请更换名称后再保存”。
3. 将数据源名称改为 `订单库A-重复连接-WARN`，连接参数保持与第 1 步完全一致，`同连接处理策略` 选择 `WARN`，期望系统允许保存，但在保存成功后弹出“重复连接提示”，说明该数据源与现有某条 `MYSQL` 连接配置相同，建议复用已有数据源。
4. 再创建一条名称不同但连接参数仍相同的数据源，`同连接处理策略` 选择 `REJECT`，期望系统拒绝保存，并提示“已存在使用相同 MYSQL 连接配置的数据源”。
5. 最后再创建一条名称不同、连接参数相同的数据源，`同连接处理策略` 选择 `ALLOW`，期望系统允许保存，且不弹出重复连接提示。
6. 抽查“数据接入”页和“数据库表导入”页中的数据源下拉，确认重复连接但不同名称的数据源会分别显示；若命中 `WARN` 保存过，系统只给提示，不影响后续测试连接、启停和导入能力。

### 数据源重复策略期望结果

- 同名数据源始终禁止保存，不依赖数据库原始异常信息。
- `MYSQL` 物理连接重复按 `ALLOW / WARN / REJECT` 三种策略执行，默认推荐 `WARN`。
- `WARN` 只提示、不阻断；`REJECT` 明确阻断；`ALLOW` 不提示也不阻断。
- `FILE` 数据源不参与物理连接重复校验。
- 重复策略仅影响“保存动作”，不影响已保存数据源的测试连接、启停、导入和删除校验逻辑。

## 数据集与元数据

- 数据集列表显示名称、来源、格式、创建时间和状态
- 数据集详情显示元数据和最近操作信息
- 元数据字段类型识别正确
- 数据预览支持分页、搜索和字段筛选
- 被治理流程、日志或导入记录引用的数据集不可直接删除
- 数据集支持导出 `CSV / JSON / Excel`

## 查询分析

- 条件查询支持多条件组合（`AND / OR`）
- 条件查询支持 `TIME_RANGE / BETWEEN`
- 条件查询支持排序与分页
- SQL 查询支持单表筛选；`/queries/sql/page` 支持排序与分页
- 非法 SQL 给出友好提示
- 图表支持与当前筛选条件联动
- 电商模板（订单趋势、销售趋势、热销排行、库存预警）可稳定返回图表与表格
- 查询结果导出支持按当前筛选条件导出（过滤模式全量导出）
- 查询结果支持导出 `CSV / JSON / Excel`

## 数据治理

- 空值处理算子有效
- 去重算子有效
- 字段转换算子有效
- 条件过滤算子有效
- 算子状态支持启停，禁用算子不可保存/执行
- 编排步骤支持上移/下移后顺序可持久化
- 多算子顺序执行后生成新数据集
- 治理过程日志可追踪

## 任务调度与日志

- 可创建导入任务
- 可创建治理任务
- 支持手动触发
- 支持暂停与恢复
- 失败任务可重试
- 日志列表支持服务端筛选（类型、状态、操作人、时间范围）
- 日志列表展示操作人
- 日志详情可查看输入参数、执行步骤、结构化失败原因、操作人
- 失败日志支持一键回放
- 任务页和日志页支持保存常用筛选视图

## 端到端验收

- 管理员创建数据源并上传文件
- 用户查看数据集并进行查询
- 用户执行治理流程生成新数据集并验证治理统计
- 用户创建定时任务并查看日志筛选结果
- 首页展示最新统计和任务趋势
